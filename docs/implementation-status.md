# Implementation status

- Current milestone: 3, speech output deployed and user-verified, with the user-requested delayed Brian handoff implemented and awaiting live confirmation; milestones 1 and 2 are deployed and the user reports production chat and appearance controls work. Antigravity remains the sole production chat provider; no Gemini fallback.
- Actual implementation: React + TypeScript + Vite frontend; aiohttp backend; text chat, cancellation, Markdown, validated conversational appearance controls, WebMCP progressive enhancement, and per-answer Play/Pause/Resume/Stop controls. Speech uses the authenticated `/api/voices` and `/api/speech` routes, a bounded MP3 cache, request limits, exact Brian voice selection, prefetched segments, and browser Daniel/default speech while the service warms or fails. When Brian is ready before Play, speech uses Brian from segment one and prefetches later segments. During a cold start, speech starts with browser voice; Brian audio for segment four is prepared during segment one, then plays at the unread boundary. If it is late, playback waits silently. If Reconnect completes later, Brian joins at the next unread segment. `edge-tts==7.2.8` is in backend requirements. Browser speech and Brian share the same text segment boundaries so handoffs continue at the next unread segment.
