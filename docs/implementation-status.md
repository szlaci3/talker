- Known defects/limits: Bug 1 reproduction: send two related turns, refresh, then ask a context-dependent follow-up. Observed before fix: Antigravity retained the topic because backend interaction IDs were keyed only by the access token, which survives refresh. Expected: the new conversation has no prior topic. Fix: scope Antigravity context to a per-page UUID sent separately from the persistent auth token. User reports the post-refresh follow-up now asks for clarification. Bug 2: assistant Markdown markers such as `**bold**` were shown literally. Fix: render assistant text with `react-markdown` and GFM; raw HTML is skipped. Production build passes; user confirms emphasis and heading markers render as styles. Invitation-attempt and daily chat counters are in-memory and reset on restart; suitable only as local guards, not public quota enforcement. One Antigravity API turn succeeded per user report; the account quota tier and sustained availability remain account-specific and unverified. Conversation state is process-local and resets with backend restarts. Gemini direct remains the fallback. Bug 3: Stop before the first streamed token left an empty assistant message in the UI history; later requests included it and the backend rejected all messages with “Messages must contain 1 to 12000 characters.” Bug 4: interrupted turns could misassociate stream deltas and desynchronize visible transcript from Antigravity context. Fixes: bind deltas to stable message IDs, include only completed turns in rebuilt request history, rotate conversation ID and clear cached Antigravity state on cancel. Build and syntax checks pass; user production retest confirms subsequent replies stay ordered and no invalid-message errors occur for cancellation before first token and during streaming. UX treatment: unanswered canceled questions now display “Canceled before a response”; partial answers display “Stopped.” The labels are separate from message text and use red-orange colors with dark-theme contrast. Native WebMCP and all voice milestones are not implemented.
