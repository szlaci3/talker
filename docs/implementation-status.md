Observed before fix: Antigravity retained the topic because backend interaction IDs were keyed only by the access token, which survives refresh. Expected: the new conversation has no prior topic. Fix: scope Antigravity context to a per-page UUID sent separately from the persistent auth token. User reports the post-refresh follow-up now asks for clarification. Production build passes; user confirms emphasis and heading markers render as styles. Bugs 3 and 4 (empty/mismatched turns after cancellation) are fixed and covered by deterministic UI tests; the user confirmed production recovery. Canceled questions and partial answers remain copyable and are colored as stale turns, with separate labels. Live Antigravity testing is opt-in, local-backend-only, and capped at seven chat calls per rolling minute. Native WebMCP and all voice milestones are not implemented.
